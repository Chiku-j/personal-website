# Pranshu Jain — Personal Website

A single-page interactive personal site: scroll-driven floating icons, reveal-on-scroll cards, tilt and glare on hover, count-up impact numbers, an active-section nav indicator, and a dark/light toggle (remembers the visitor's choice and defaults to their system setting). Everything respects `prefers-reduced-motion`.

- `index.html` — the whole site (HTML + CSS + vanilla JS, no build step)
- `assets/pranshu.jpg` — profile photo
- `assets/Pranshu_Jain_CV.pdf` — downloadable résumé
- `archive/v1-canva/` — the earlier static version based on the Canva design (kept for reference, not linked from the site)

## Publish with GitHub Pages
1. Make the repository public (Settings → General → Danger Zone → Change visibility).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save.
3. The site will be live at `https://<your-username>.github.io/personal-website/` within a minute or two.
