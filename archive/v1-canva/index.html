05 DA payout reconciliation fix

Problem

Finance flagged mismatches between DA payout files and bank reconciliation across transactions.

Approach

Traced the root cause: originator collection dates differed from JCL's receipt dates, and both originator and JCL share files were kept in the system. Moved to a single JCL-share file in the LMS, built a Google Sheets calculator for part payments and rate changes, and wrote a Python validator to check originator data before upload.

Outcome

A single source of truth for DA accounting, with duplicate file maintenance removed from operations.

Skills

  • Root-cause analysis
  • Financial reconciliation
  • Process redesign
  • Python
